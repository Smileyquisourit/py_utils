======================
py_utils documentation
======================

The main objects of this package already exists in the standard implementation of Python, the reason of this package was mostly to
practice and gain hands-on experience with building and structuring a complete Python package. This package contains to main components:

- A logging system, inspired by the Logger module of Python's standard library

- And a configuration utility, inspired by the ConfigHelper module of Python's standard library.

Check out the :doc:`usage` section for further information.

.. note::

   This package is not intended to replace standard solutions, but was rather an exercise for getting valuable learning experience.
